# Student notebooks

These files use stable analytical identifiers, `NB00` through `NB19`. Canvas and the course launch hub link directly to these paths.

Before working, students should open the assigned notebook in Colab and select **File → Save a copy in Drive**. The repository copy is a clean course distribution copy and should not contain student results.

Every notebook now has a permanent `main`-branch Colab badge and automatically
recognizes both supported Google Drive layouts:

- student: `MyDrive/BIOINFO4-5203-F26/`
- instructor: `MyDrive/Teaching/BIOINFO4-5203-F26/`

`NB04_pairwise_alignment.ipynb` is currently the developed cytochrome c
activity. The remaining files are launch-ready development shells awaiting
their full instructional workflows and starter-data validation. Their status is
displayed prominently at the top so they are not mistaken for finished lessons.
