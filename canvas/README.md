# Canvas integration

Use `colab_links.csv` for current Colab-backed assignments and `assignment_crosswalk.csv` for all Canvas assignments, their numeric IDs, Dropbox HTML archive paths, canonical notebook filenames, Colab launch URLs, and publication states.

The student-facing URL pattern is:

```text
https://colab.research.google.com/github/RobBurnap/Bioinformatics-MICR4203-MICR5203/blob/main/notebooks/Assignment_XX_...ipynb
```

Use the `main` branch in Canvas only after a notebook is present there. The numbered assignment filenames are canonical; old NB-prefixed filenames are retained in `legacy/notebooks/` with a notice linking to their replacement.

Assignments 10 and 11 are currently unpublished Canvas drafts. Preserve their publication status when updating links.
